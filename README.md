# Catastrophe Reinsurance Recoverable Management

Accelerate catastrophe recoveries by allocating event losses through treaty towers and governing notices, proofs, and collections.

**Primary buyer:** Property insurers and reinsurance teams. **Evidence:** catastrophe events, claims, loss estimates, occurrence definitions, hours clauses, retentions, limits, reinstatements, notices, bordereaux, collections, and cash.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Catastrophe event registry
- Claim loss ingestion
- Occurrence definition analysis
- Hours-clause grouping
- Ultimate loss estimate
- Retention erosion
- Layer allocation
- Limit exhaustion
- Reinstatement premium
- Cash call calculation
- Notice deadline control
- Proof-of-loss package
- Reinsurer query workflow
- Collection reconciliation
- Event tower analytics
